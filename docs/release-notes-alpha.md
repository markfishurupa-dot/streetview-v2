# StreetView 2.0 alpha release notes

The [v2.0.0-alpha.6 prerelease](https://github.com/markfishurupa-dot/streetview-v2/releases/tag/v2.0.0-alpha.6) is public and includes the signed Android 1.3.0 APK.

The alpha includes Android capture source and a self-hosted portal for importing MP4 and GPS recordings, validating tracks, extracting photographs, exploring a map, correcting points and bearings, exporting GIS data, and publishing read-only survey maps. The public static demo contains a real survey and its data-use rights remain under review.

The portal has one administrator and one processing worker. Docker Desktop with Linux amd64 containers has been exercised. Android physical-device testing of the exact released APK, native Linux installation, backup and restore, third-party redistribution, and final branding and privacy reviews remain release gates.

See [the release checklist](public-release-checklist.md) for verification evidence and outstanding owner decisions.
